Moth Pass

Burn $DMOTH once. Get passes that unlock optional premium privacy features. Your browser blinds each pass before issuance; the server checks the finalized pass only when it is spent.

  1. 01Burn

    Burn $DMOTH from any wallet. One public transaction, visible to anyone.

  2. 02Blind-sign

    Your browser blinds random passes. Duskmoth signs them without seeing the finalized passes.

  3. 03Spend

    Each premium action spends one pass. The server checks it is genuine and unspent.

Passes are bearer credits: anyone with the backup file can spend them, and clearing this browser deletes them.

Best practice

Burn from a different wallet than the one you send with, and wait before spending. The burn itself is public, and timing or network metadata can still correlate activity.

What the server stores

Redeemed burn signatures and hashes of spent passes. It does not store anything linking a burn to a pass.

What $DMOTH is not

$DMOTH is an ordinary SPL token with public transfers, not a privacy coin. Duskmoth works fully without it.
